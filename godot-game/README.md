# Coin Jumper

Простой 2D-платформер на Godot 4.3: собери все монеты на платформах.

## Как запустить

1. Скачайте Godot 4.3 (или новее из ветки 4.x) с https://godotengine.org/download — установка не нужна, просто распакуйте.
2. Запустите Godot → **Import** → выберите файл `godot-game/project.godot`.
3. Нажмите **F5** (или ▶ в правом верхнем углу).

## Управление

| Клавиша | Действие |
|---|---|
| ← → | бег |
| Пробел / ↑ | прыжок (в воздухе можно прыгнуть ещё раз) |
| R | начать заново |

## Структура

- `scenes/main.tscn` — уровень: земля, платформы, монеты, игрок, интерфейс
- `scenes/player.tscn`, `scripts/player.gd` — персонаж (бег, двойной прыжок, возврат на старт при падении)
- `scenes/coin.tscn`, `scripts/coin.gd` — монета
- `scenes/platform.tscn`, `scripts/platform.gd` — платформа, размер и цвет задаются в инспекторе
- `scripts/main.gd` — подсчёт монет и перезапуск
