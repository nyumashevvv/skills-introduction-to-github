# Кристаллы Листвянки

Пиксельная 2D-бродилка для iPhone (и любого браузера). Буря разбросала пять кристаллов по округе. Найди их и верни старому Мирону.

## Управление

| Телефон | Клавиатура | Действие |
|---|---|---|
| Крестовина | Стрелки / WASD | Ходить |
| A | Z / Пробел / Enter | Говорить, открывать сундуки, бить оружием |
| A (держать на месте) | Z (держать) | Щит, если он куплен |
| B (держать) | X / Shift | Бежать |
| Сумка | I | Оружие, зелья, снаряжение |
| Меню | Esc | Пауза, новая игра |

В деревне есть лавка Вари (зелья, копьё, топор, щит) и кузница Гордея (заточка, кольчуга, длинная рукоять). Монеты падают со слаймов и из высокой травы, которую можно косить оружием.

Прогресс сохраняется в браузере автоматически.

## Файлы

- `game.html`: исходник игры (один файл, без зависимостей кроме шрифта Pixelify Sans).
- `build.sh`: собирает из него `docs/index.html`, полноценную страницу с мета-тегами для экрана «Домой» на iPhone.

## Как поставить на iPhone через GitHub Pages

1. Settings → Pages → Source: «Deploy from a branch», ветка с этим кодом, папка `/docs`.
2. Откройте адрес `https://<логин>.github.io/skills-introduction-to-github/` в Safari.
3. «Поделиться» → «На экран „Домой“». Игра запустится на весь экран, как приложение.
