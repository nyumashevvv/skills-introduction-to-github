# Рассрочка.Брокер

Демо-сайт брокера рассрочек: одна заявка отправляется сразу в несколько банков-партнёров.
Чистые HTML/CSS/JS, без сборки — откройте `index.html` в браузере.

## Что есть
- **Hero** с анимированной «орбитой» банков, печатающимся заголовком и счётчиками.
- **Подключённые банки** — карточки с 3D-наклоном и подсветкой за курсором, фильтры.
- **Калькулятор** — сумма и срок; банки сортируются по платежу с анимацией, лучший выделен.
- **Заявка** — валидация, маска телефона, имитация скоринга в каждом банке и список одобренных предложений.
- Шаги, FAQ, адаптив под мобильные, поддержка `prefers-reduced-motion`.

## Банки
Список и условия — массив `BANKS` в `script.js` (`fee` — переплата в % годовых, `maxTerm`, `maxSum`,
`decision` — минуты до решения, `chance` — вероятность одобрения в демо).
Названия банков вымышлены. Для реальной интеграции замените `runScoring()` на запросы к API банков.
